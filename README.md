🔐 Password Strength Checker

About

A beginner-friendly Python project that checks password strength using basic security criteria.

Features

- Checks password length.
- Identifies uppercase and lowercase letters.
- Checks for numbers and special characters.
- Classifies passwords as Weak, Moderate, or Strong.

Technologies Used

- Python
- Regular Expressions (re module)

How to Run

1. Install Python 3.
2. Download "password_checker.py".
3. Open a terminal in the project folder.
4. Run the following command:

python password_checker.py

5. Enter a sample password to check its strength.

Learning Objectives

- Practice Python functions and conditional statements.
- Learn basic password security concepts.
- Understand regular expressions.

Disclaimer

This project is for educational purposes only. Use sample passwords for testing. Do not enter your real passwords.
